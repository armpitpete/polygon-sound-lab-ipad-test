## Non-negotiable rules
1. **Discover existing work before rebuilding.** Inventory this repo, its Git history and linked Polygon resources. The original v0.1.7 source and complete preset definitions are here; don't report them missing.
2. **Do the work if authorised and tools permit it.** A recommendation is not completion. Keep progressing through unblocked tasks.
3. **Evidence for every PASS.** Verify changed commits/files, SHA-256 where meaningful, sound parity, actual Windows browser behaviour and any necessary user acceptance. No confidence-based PASS.
4. **Report all statuses explicitly.** PASS, FAIL, BLOCKED, NOT ATTEMPTED, IN PROGRESS, DEFERRED; reconcile task counts.
5. **Protect accepted material.** No edits to frozen `index.html`, accepted synthesis/presets, or historical acceptance statements without explicit approval and an isolated candidate.
6. **Keep scopes separate.** Standalone Sound Lab v0.1.7 is user-accepted; Polygon SEQ v4.8.6 integrated candidate and v4.9 preview are **not** thereby accepted. Windows first; iPad secondary.
7. **Owner decisions only when necessary.** Do not ask for routine tool use or previously settled decisions. Escalate real product, irreversible, safety or release decisions.
8. **Update authoritative records** when work changes, and leave a concise verifiable handoff.

Read-only verifications and documentation-only corrections to these records may proceed without touching frozen audio/software. If a repository does not contain the needed project source, record where it actually lives rather than claiming the project has been recovered into Git.

This file documents project working practice; it cannot itself guarantee that an unrelated ChatGPT session or agent will read it. Future work must explicitly begin with the repository's current records.
