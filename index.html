Prototype boundary: This is a separate four-voice experimental percussion synthesizer, not a new version of the Polygon sequencer. There is no network use, third-party code, automatic update, or change to existing project files. Sounds render to 44.1 kHz 16-bit mono WAV. Presets are editable JSON; a WAV is audio, not an editable synthesis preset. Factory presets are immutable. Active kit assignments are temporary; save sounds individually. Backup custom sounds before clearing browser data. Recommended first use: Windows Chrome or Edge.
