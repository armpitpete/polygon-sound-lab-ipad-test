# Polygon Sound Lab v0.1 — iPad Safari test

Experimental, publicly accessible standalone browser test for Polygon's **four-voice experimental percussion synthesizer**. This repository and site are not a main Polygon release.

Open the GitHub Pages site in iPad Safari. Tap a voice Play button to unlock browser audio; change sound controls; save a preset; export a WAV or JSON backup.

Important limitations:
- Safari sound playback, downloads and persistence require real-device testing.
- Saved presets live in this browser's localStorage and may disappear when site data is cleared. Export JSON backups.
- No data is uploaded to this test site; synthesis is client-side.
- Do not merge with the accepted Windows percussion sequencer until Windows PC acceptance.
